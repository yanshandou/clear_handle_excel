# 精灵图清单（SVG 草稿）

一共 **168** 个图标，分 13 组。打开同目录的 `index.html` 能看到每个图标的 SVG 草图（透明底、带编号），可以直接导出 PNG 精灵图和位置表。

| 组 | 个数 | 显示尺寸 |
|---|---|---|
| 主页工具卡 | 18 | 大卡 136px，画 256px |
| 顶部导航 | 9 | 16–20px，画 128px |
| 状态徽章 | 15 | 16–28px，画 128px |
| 提示条和对话框 | 8 | 提示条 24–28px，对话框 32–40px，画 128px |
| 按钮动作 | 30 | 16–20px，画 128px |
| 文件和对象 | 12 | 14–20px，画 128px |
| 说明块小标题 | 18 | 18–22px，画 128px |
| 分级和标记色 | 8 | 12–16px，画 128px |
| 调整页面工具 | 8 | 20–24px，画 128px |
| 查看切字工具和分类 | 14 | 20–24px，画 128px |
| 进度和动效 | 9 | 24–48px，画 128px |
| 空状态插画 | 6 | 120–200px，画 256px |
| 上传管理页（可选） | 13 | 16px，画 128px |

## 怎么用

- 编号固定，英文名以后对应 CSS 的 `.icon-英文名`；美化时按编号对照，每格同样大小、图标居中、四周留约 10% 空白、透明底。
- 建议画成两张图：① 主页工具卡 + 空状态插画用 256px 一格（显示到 136px，高清屏够用）；② 其余小图标用 128px 一格（显示 16–40px）。
- 进度条底槽、进度条填充、完成横幅丝带要能横向拉伸：画成 256×64，左右两头各留 1/4 不拉伸。
- 标「可复用」的几个（说明块的放大镜、齿轮、循环）可以直接用同一张图，不用另画。
- 「上传管理页」那组现在用 lucide 线条图标、自成一套风格，要不要换由你定。
