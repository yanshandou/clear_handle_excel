把游ゴシック换回标准字体ＭＳ Ｐゴシック

📖 程序会怎么做 图形里和有内容的格子里，游ゴシック 一律换成ＭＳ Ｐゴシック，别的不动

🤔 为什么要换

  • 游ゴシック比ＭＳ Ｐゴシック宽、行距大，原来放得下的字会被挤出去，查切字时报成误报，多半出在图形（对话框、文本框）里。

🔤 换哪些

  • 只认游ゴシック一家：游ゴシック、游ゴシック 本文、游ゴシック Light、半角写的 游ｺﾞｼｯｸ、Yu Gothic / Yu Gothic UI 都算（不管全角半角、大小写、空格）。
  • 图形：每个图形里的每一段文字各自判断（组合图形拆开看里面的每一个），游ゴシック的那段换成ＭＳ Ｐゴシック，西文、日文字体一起换；别的段、字号、颜色不动。
  • 格子：只看有内容、字体是游ゴシック的格子，整格换成ＭＳ Ｐゴシック；字号、颜色、粗体等不变。
  • .xls / .xlsb 只改图形，格子查不了。

🚫 不碰的

  • 不改 Excel 的「標準」样式：改了整张表的标准列宽、行高都会变。
  • 空白格子、别的字体、行高列宽都不动。
  • 一处都不用换的文件不保存；文件正在 Excel 里打开时不改。改完直接保存，没有确认这一步。

🔗 和精简 Sheet 的关系

  • 精简 Sheet「确认执行」后默认会接着自动做这一步（精简页底部「做完后顺便做」可以勾掉）。这一页是单独跑用的。
