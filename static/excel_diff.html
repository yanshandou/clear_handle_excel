对比哪两份

📖 程序会怎么做 像 Git 一样左右两栏列出两份 Excel 的所有差异，只读，不用关 Excel

📋 比哪些

  • 表：只有一边有的表单独列出；精简 Sheet 本来就会删的表（変更履歴、备份表、灰色标签、空白表等）另外标出，不算差异。
  • 每个格子：显示的文字、公式、批注、超链接、字体（名字、字号、粗斜体、下划线、删除线）、字的颜色、填充色、边框、对齐 / 换行、数字格式、保护。
  • 整张表：行高、列宽、隐藏的行列、合并单元格、冻结窗格、打印设置（打印区域、方向、缩放、纸张）、图片和图形（多了少了、图片换没换、挂在哪个格子、大小、图形和文本框里的字）、标签颜色、表是否隐藏、条件格式条数。

👀 怎么看

  • 左边是远程现在这份（旧），右边是你要上传的这份（新）。
  • 真实效果：有不同的表（和只有一边有的表）用后台 Excel 真导一次 PDF，和上传的同名 PDF 一样的印法（宽一页、去掉本工具的标记色；页眉页脚照原样）。两边每一页逐像素比，印出来不一样的地方左边盖红、右边盖绿；图片换了、挪了也看得出来。完全一样的页收起来。一边没有的页整页盖色。
  • 导 PDF 要等一会儿（每张表几秒），排队一份一份导；导好的按文件内容记下来，文件没变再看不用重导。复制一份再只读打开，原文件不动；别的任务在跑也能用。
  • 上面哪一行变高了，下面的内容会整体往下挪，那几页会大片红绿。这时具体改了什么，看下面的差异清单。
  • 「🧩 按格子画的示意图」是程序照格子画的（不是真实效果），收在下面，想看具体哪一格时展开。
  • 下面是逐条的差异清单；点类型按钮可以暂时不看某一类。差异太多时，每张表文字 / 公式最多列 400 处，每类样式最多列 60 组。
  • 点表名可以在 Excel 里打开那张表。

⚠️ 比不了的

  • 图片只比文件内容是不是同一张，说不出画面上哪里不同；位置按挂在哪个格子、大小按文件里记的宽高（0.1 厘米）比。
  • 图形的线条颜色、填充色、粗细不比；批注框和表单控件（按钮、下拉框）不比。
  • 不开 Excel、直接读文件，所以只支持 .xlsx / .xlsm。

⬆️ 从上传页进来时

  • 上传时远程那份和开工时记下的版本对不上（或你选了「逐份做 Excel 对比」），会一份一份带到这里，自动开始对比。
  • 看完点「确认覆盖并上传」才传这一份；「跳过这份」不传。
  • 从上传页的清单（当前任务，或「起点 → 终点」还没执行的清单）点「🔍 对比」进来：对比完上面会多一个「⬆ 没问题，上传这一份」，点了就只传这一份。
  • 传表格、表格和 PDF 一起、还是只传 PDF，按上传页选好的来；终点已经有同名 PDF 时会问一次要不要覆盖。
  • 上传那一刻两份文件还是你看的这两个版本才直接传；变了的话，当前任务回上传页逐份确认，「起点 → 终点」要回上传页重新生成清单。
  • 「起点 → 终点」传成的那一份会从清单里拿掉，其余的不用重新生成清单。
