已筛选 0 / 0

键盘 ← 保留、→ 跳过、Backspace 撤销；也可以按住卡片向左 / 向右拖动。跳过会立即保存，保留只记录在本浏览器里，用来标记已看过。

① 逐个查看每一处：无需修改的跳过（→），需要修改的保留（←）。卡片上可以「在 Excel 中定位」直接跳到单元格。② 保留的在 Excel 中修改并保存。③ 再点「扫描切字」：只检查改过的文件，不再有问题的自动记为已修复。

标【隐藏截断】的：PDF 外观正常，但单元格内容没显示全（行高或列宽不够），卡片上会写出完整内容和 PDF 里实际显示的部分。跳过的位置以后不再检查；未修改的文件直接沿用上次结果。
