在 Excel 中修改并保存后，再点上方「扫描切字」复检，改好的会自动记为已修复。
💡 标记图例： 蓝色框 = 待人工修改（标「新」= 本次复检新发现） 灰色虚线框 = 已跳过（人工确认无需修改） 绿色 = 已修复（复检未再检出） 橙色框 = 已在 Excel 中定位 / 需人工复检 🔍 悬停可看 2.5x 放大镜；点击框即可跳过，再点一次撤销

① 先人工筛一遍：无需修改的位置点击问题框跳过（或用「🃏 逐个筛选」），再点一次撤销。② 剩下的在 Excel 中人工修改（可点「在 Excel 中定位」直接跳到单元格），保存。③ 再点「扫描切字」：只检查改过的问题文件里有问题的工作表，不再压线的自动记为已修复。

跳过和已修复的位置以后都不会再检查；未修改的文件直接沿用上次结果，不会重新打开。保存 Excel 不会让跳过失效。勾选「只看待处理」可隐藏已跳过和已修复的项。
