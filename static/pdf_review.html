📄 这里看到的 PDF

  • 主页「调整页面」导出的 PDF：每张表一份，放在根目录的 PDFS 文件夹里。导出时每张表都设成宽一页、高自动：横向不会拆成几页，纵向几页由 Excel 定。
  • 打开这一页时，导出以后 Excel 又改过、保存过的表（程序改的或你自己改的）标「⚠ Excel 改过」，后台自动重新导出成最新的。
  • 导出时发现内容很少的页：有把握的已经自动修好（比如手动分页造成的空页就清掉手动分页再核对）；没把握的那一页标「⚠ 内容很少」、自动标黄。

🔘 每张表的按钮（只是做标记，再点一次取消）

  • 方向：竖向 / 横向。
  • 页高：高自动 / ⤓ 取整（N 页 → N-1 页）。末页只多一点（两页以上、最后一页印了不到 20%）的表自动标黄、建议取整；不想取整就点一下「⤓ 取整」取消。点了取整就一定改，字缩得太小时只在结果里提醒。
  • 删除这张表：标红，「统一修改」时从 Excel 里删掉。
  • 有手动分页的表还有 ✂ 清手动分页：全部清掉，改成 Excel 自动分页；看了新的 PDF 再决定要不要取整。
  • 上面的分类只看某一类的表，还能一次给这一类做标记（比如末页只多一点的全部取整）。

🛠「统一修改」

  • 后台按标记改 Excel、保存，再只重新导出改过的那几张表；同一份 Excel 别的表的 PDF 不动。右下角进度框显示正在改哪份、每张表的结果。
  • 改了方向以后要不要取整就不一定了，看新的 PDF 再决定。可以来回改好几轮，都没问题了点「🏠 返回首页」。

✋ 自己在 Excel 里改

  • 单击页面看大图；点标题上的 Excel 路径，或按住 Ctrl 单击页面（或右键菜单），Excel 打开并跳到那一页。
  • 改完保存后点这张表的「🔄 重新生成」：只重新导出这一张表，一定重新导出。这张表上点了方向、取整等还没改的，会先改进 Excel 再导出。
  • 填了参考文件夹时，打开 Excel 会把原版也只读打开、跳到同一块，左右并排对照。
  • 顶栏和底部条不碰 3 秒自动隐藏，鼠标移到窗口最上面或最下面就会出来。

输入文件夹后点「加载 PDF」。
