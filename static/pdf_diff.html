      📖 程序会怎么做 把两边的 PDF 各自接起来，抽出文字逐行比，像 Git 一样左右对照；原文件不动

      📥 放文件

      • 把 PDF 拖到左边或右边的框里，也可以点「选择文件」。一次可以拖好几份。
      • 每边的几份按列表里的顺序接起来再比。例：A + B 应该等于 C，就把 A、B 拖到左边，C 拖到右边。
      • 顺序不对可以按 ↑ ↓，或者直接拖着列表里的文件换位置；拖到另一边就换到另一边。✕ 是拿掉这一份。
      • 文件会先复制一份给程序读，原文件不动；复制的那份放在程序数据的 pdf_diff 文件夹，过一天自动删掉。

      🔍 怎么比

      • 只比文字：每页把同一高度的字连成一行（Excel 导出的 PDF，一行就是表里的一行），两边所有行接起来以后逐行比。
      • 改了的行，具体哪几个字不同再用深色标出来。
      • 「不管空格」：空格、全角空格多一个少一个都不算不同。
      • 「不比页眉页脚」：每页最上面、最下面两行里，只有页码的行（「3」「- 3 -」「3 / 12」「Page 3」「3ページ」这类），和左右两边一半以上的页都在这个位置重复出现的行（标题、公司名、每页重复的表头）不比。接起来以后分页、页码本来就对不上。
      • 页和页之间不算内容：A 的最后一页和 B 的第一页接起来，只要文字一样，分页位置不同也不算不同。

      👀 怎么看

      • 左边红色是左边有、右边没有（或被改掉）的行，右边绿色是右边新的行；改了的行左右对齐。
      • 行号旁边的小标签（如 A 3）是这一行在哪份文件的第几页；点它在浏览器里打开那份 PDF 的那一页。
      • 一样的行默认折起来，只留不同处上下各 3 行；点「展开」看全部，或者取消勾选「只看不同」。
      • 「▲ 上一处 / ▼ 下一处」在不同处之间跳。

      ⚠️ 比不了的

      • 图片、线条、颜色、字体大小不比；扫描出来的 PDF（整页是图片）抽不到文字，比不了。
      • 同一行里的字是按左右位置接起来的，表格里换了行的格子可能被拆到上下两行。

      对比结果

      左右两边都放好 PDF 后点「🔍 开始对比」。

      批量对比：贴路径

      一行一组：左边几份用 + 连起来，= 后面是右边。路径带不带引号都行；同一行后面的文件和前面在同一个文件夹时，可以只写文件名。上面的「不管空格」「不比页眉页脚」也用在这里。

      📖 还能怎么写 也认 JSON；空行和 # 开头的行不管

      ✍️ 一行一组

      • A.pdf + B.pdf = C.pdf：左边 A 接 B，右边 C。右边也可以写好几份：A.pdf = B.pdf + C.pdf。
      • 文件名里本身有 + 或 = 也没关系：只有紧跟在「.pdf」后面、或者前后有空格的 + = 才算分隔。
      • 只写文件名（不带文件夹）时，用同一行前面那份的文件夹；一行的第一份也只写文件名时，用上一行最后那份的文件夹。

      🧾 JSON

      • [{"left": ["C:\\x\\A.pdf", "C:\\x\\B.pdf"], "right": ["C:\\x\\C.pdf"]}]
      • 也可以写成 [[["A.pdf", "B.pdf"], ["C.pdf"]], …]，一边只有一份时可以直接写字符串。

      👀 结果

      • 一组一组按顺序比，比完一组马上出一张卡片，不用等全部做完；同一份 PDF 在几组里出现只读一次。
      • 卡片上写一样、有几处不同、或者出错的原因；点卡片展开，和上面一样左右对照看。
      • 只读，原文件不动；别的任务在跑也能用。
