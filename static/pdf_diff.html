      把 PDF 拖到这里
      可以一次拖好几份，按放进来的顺序接起来
      📖 程序会怎么做 两边的页按顺序一页对一页放原图，逐像素比，不一样的地方左边圈红、右边圈绿；原文件不动

      📥 放文件

      • 把 PDF 拖到左边或右边的框里，也可以点「选择文件」。一次可以拖好几份。
      • 每边的几份按列表里的顺序接起来再比。例：A + B 应该等于 C，就把 A、B 拖到左边，C 拖到右边。
      • 顺序不对可以按 ↑ ↓，或者直接拖着列表里的文件换位置；拖到另一边就换到另一边。✕ 是拿掉这一份。
      • 文件会先复制一份给程序读，原文件不动；复制的那份放在程序数据的 pdf_diff 文件夹，过一天自动删掉。

      🔍 怎么比

      • 两边的页接起来以后一页对一页：左边第 1 页对右边第 1 页，第 2 页对第 2 页……（A 有 2 页、B 有 2 页，接起来左边第 3 页就是 B 的第 1 页）。
      • 每一对页都变成图片，缩放到一样宽，逐个像素比颜色。抗锯齿、压缩噪点这种肉眼看不出的差别、错开 1 像素以内的不算。
      • 不一样的地方连成一块块（离得近的并成一块），每块画一个框：左边红框、右边绿框。
      • 一边页数多出来的页，整页盖红（只有左边有）或盖绿（只有右边有）。

      👀 怎么看

      • 默认只显示不一样的页；勾选「一样的页也显示」可以看全部。
      • 「▲ 上一处 / ▼ 下一处」在不一样的页之间跳。
      • 每页上面写着这一页是哪份文件的第几页（A、B、C 是放进来时定的字母）；点图片在浏览器里打开那份 PDF 的那一页。
      • 比完一页显示一页，不用等全部比完。

      ⚠️ 要注意

      • 是按页对齐比的：前面多了或少了一行，后面整页内容往下挪，这一页会大片圈框；前面多了一页，后面每页都对不上。
      • A + B 和 C 的分页要一样（比如 C 就是 A、B 直接合起来的）才能一页对一页；页码印在页面上时，页码那里会被圈出来。

      对比结果

      左右两边都放好 PDF 后点「🔍 开始对比」。

      批量对比：贴路径

      一行一组：左边几份用 + 连起来，= 后面是右边。路径带不带引号都行；同一行后面的文件和前面在同一个文件夹时，可以只写文件名。

      📖 还能怎么写 也认 JSON；空行和 # 开头的行不管

      ✍️ 一行一组

      • A.pdf + B.pdf = C.pdf：左边 A 接 B，右边 C。右边也可以写好几份：A.pdf = B.pdf + C.pdf。
      • 文件名里本身有 + 或 = 也没关系：只有紧跟在「.pdf」后面、或者前后有空格的 + = 才算分隔。
      • 只写文件名（不带文件夹）时，用同一行前面那份的文件夹；一行的第一份也只写文件名时，用上一行最后那份的文件夹。

      🧾 JSON

      • [{"left": ["C:\\x\\A.pdf", "C:\\x\\B.pdf"], "right": ["C:\\x\\C.pdf"]}]
      • 也可以写成 [[["A.pdf", "B.pdf"], ["C.pdf"]], …]，一边只有一份时可以直接写字符串。

      👀 结果

      • 一组一组按顺序比，比完一组马上出一张卡片，不用等全部做完；同一份 PDF 在几组里出现只读一次。
      • 卡片上写一样、有几页不一样、或者出错的原因；点卡片展开，和上面一样逐页看原图和红绿框。
      • 只读，原文件不动；别的任务在跑也能用。
