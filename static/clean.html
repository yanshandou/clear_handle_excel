精简 Sheet

扫描全部工作表（含子文件夹），单击标签即可在「保留 / 删除 / 待定」三种状态间切换

📖 程序会怎么做 按表名、标签颜色和内容自动标好保留 / 删除 / 待定，你改完点「确认执行」才真正删

🗑 不用找原表，默认「删除」

  • 自動生成：名字以「自動生成」开头的表（如 自動生成_引数、自動生成_JSON）。
  • 変更履歴：名字就是「変更履歴」的表（空格、全角半角不计），或带日期等备份标记的（如 変更履歴_20220101）；「変更履歴一覧」这类多出别的字的不算。
  • 明确写着备份：名字含 bk / ｂｋ / BK / bak / backup / バックアップ / 备份（后面可接编号，如 写真管理ｂｋ２）；Bkup、SBK 这类单词内部的不算。
  • 标着 old：old / OLD / ＯＬＤ，带不带括号、在开头或末尾都算（如「エラーログ出力手順 (ＯＬＤ)」「OLD_一覧」）；Folder、Holder 这类单词内部的不算。
  • 旧开头：名字以「旧」开头的表，不要求有同名原表或「新」表（只有 レイアウト(1ページ)、レイアウト(複数ページ) 和 旧レイアウト 时，旧レイアウト 也删）；「新旧対照表」「復旧手順」不算。
  • 没有内容：整张表空白，或只有一格写着「無」「なし」「該当なし」「－」「ー」「N/A」这类占位字，或几格合起来只是空的 JSON（如 A1=[、A2=]），而且没有图片、图形、批注。
  • 灰色或纯黑标签：Excel 里标签是灰色（白色深色 5%～50%、黑色浅色 5%～50% 这类）或纯黑的表；纯白、蓝灰不算。
  • 没有内容、灰色 / 黑色标签这两条不看名字；鼠标停在标签上会提示是哪一条。

🗑 有原表时才默认「删除」

  • 带日期：20220929，或 2018-02-26、(2018.02.26) 这类带分隔符、带括号的写法；两位年份的年月日写在末尾或开头，如 _170120（=2017-01-20，年份不晚于今年）、171013_お客様助成明細ビュー；末尾不带年份的月日，如 0513。
  • 复制出来的：コピー / copy / 副本，或「(2)_20221005」这种编号后面又接了日期的。
  • 同一工作簿里要有去掉这些标记后的原表，才默认删除；原表和备份表的同名部分用马克笔下划线标出。
  • 末尾四位月日前不能紧挨数字或英文字母：「SSSEE0114」按编号保留，「SSSEE0114_20231023」有原表 SSSEE0114 时按日期备份删除；英文表名的月日要带分隔符，如「Report_0513」。
  • 多个日期版本：同一个名字有几个日期版本、却没有不带日期的原表时（如 20170113要介護度別状況調査表、20161207要介護度別状況調査表），只留日期最新的一个，其余删除。

✅ 默认「保留」

  • 编号后缀：名字末尾是「(2)」「（３）」这类括号里 1～3 位数字的表，一律默认保留，就算有原表、标签是灰色、表是空的也保留；需要时手动改成删除。同一原表有 (2)(3)… 两张以上时算一组正式的多页表，导出 PDF 也照常导出。
  • 括号里是日期的（如「(20220916)」「（2022-09-16）」）不是编号，有原表时按日期备份删除；编号后面另接日期的也不算编号。
  • 「レイアウト_オプション」不会只因为名字里有「レイアウト」就标待定。
  • 上面哪条都不符合的表都保留。

❓ 默认「待定」（这次不删、不改名）

  • Excel 默认名：「Sheet1」「Sheet 2」「Sheet」「工作表1」这类（全角半角、大小写都算），多半是临时表；表里没内容的照样默认删除。「SheetA」「集計Sheet1」不算。
  • 名字包含另一张表：名字完整包含同一工作簿另一张表的名字、但多出的部分不是上面的标记（如「一覧」与「一覧詳細」），可能是备份也可能是正式明细表。这些不算：Sheet1 与 Sheet12 这种数字连在一起的；多出的部分整段在括号里的（「レイアウト」与「レイアウト(介護給付費請求書1)」）；自己有备份表的原表；只在前面多出一段的（「サンプル」与「JSONサンプル」，仮 / 作業用 / テスト / new / tmp 这类临时前缀除外）；后面只多出英文词的（「一覧」与「一覧CSV」）；前后都多出英文词、把原名包在中间的（「vwcmok15」与「DbVwCmok15Mapper」）。
  • 待定的表这次保留不删，文件名和表名都不改；可以点「🖼 预览」看过再定。

✏️ 自动去掉「新」字

  • 同时有「新X」和「旧X」（括号前有无空格、全角半角都算，如 新レイアウト(介護給付費請求書1) 与 旧レイアウト (介護給付費請求書1)）且旧表全部删除时，执行后「新X」改名为「X」，标签上「新」字带删除线。
  • 没有「旧」表的「新X」也去掉「新」字（新レイアウト（２ページ以降） → レイアウト（２ページ以降）），按去掉后的名字判断要不要待定。「新規」「新旧」「新着」这类「新」是词的一部分的不改。
  • 不改名的情况：旧表没有全部删除、新表被标为删除或待定、去掉后和现有表重名、你手动改过这张表的名字。
  • Excel 会自动更新公式和打印区域里的表名。

🖱 你可以怎么改

  • 单击标签：保留 → 删除 → 待定 → 保留循环切换，只靠颜色区分；每个工作簿至少保留 1 张表。
  • 🖼 预览：新标签页里看这份文件每张表打印出来的第 1 页，单击预览图同样能切换状态、和本页同步，还会提示内容完全相同或高度相似的表。点底部「✓ 标记完成，返回精简 Sheet」（或左上方「← 返回精简 Sheet」）回来，刚才那张卡片边框会发亮。
  • 改表名：在预览里单击卡片下方的表名（最多 31 个字，不能含 : \ / ? * [ ]，不能和本文件剩下的表重名），回车确认、Esc 取消，清空或改回原名就是撤销；本页标签显示「✏️ 新名字」，「恢复默认」或重新扫描也会撤销。标为删除的表不改名。
  • 不记住上次手动选的：每次扫描都按上面的规则重新标。

⚙️ 点「确认执行」以后

  • 删表前：别的表里引用了待删表的公式，先改成现在算出来的固定值（格式保留）。有公式转不了值，或删完出现新的引用错误，这份文件不保存。改名和删表一起做。
  • 接着自动检查（看底部「做完后顺便做」的勾）：排查 BL 超链接（扫到就直接清除）→ 修复引用错误 → 修复隐藏页 → 统一字体（游ゴシック 换成ＭＳ Ｐゴシック）。默认勾 BL、引用错误、统一字体，隐藏页默认不勾。每份 Excel 只打开、保存一次，改不了的列在下面。
  • 引用错误和隐藏页要对照「默认参考文件夹」，没填就跳过这两步并写明原因。
