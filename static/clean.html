精简 Sheet

扫描全部工作表（含子文件夹），单击标签即可在「保留 / 删除 / 待定」三种状态间切换

使用说明
  • 自动递归扫描所选文件夹及其所有子文件夹下的 Excel 文件
  • 自动初筛：名称含日期（20220929，或 2018-02-26、(2018.02.26) 这类带分隔符、带括号的写法，以及末尾不带年份的月日如 0513）、bak / backup / bk、old / 旧（「新旧」「復旧」除外）、バックアップ / 备份、コピー / copy / 副本，或复制产生的「(2)」「（３）」后缀（后面可再接日期，如「(2)_20221005」），且同工作簿存在原表的，默认标为「删除」（同一原表有 (2)(3)… 两张以上编号时算一组正式的多页表，全部保留，导出 PDF 也照常导出），并用马克笔下划线标出原表与备份表的同名部分
  • 末尾四位月日前不能紧挨数字或英文字母：如「SSSEE0114」按编号保留，「SSSEE0114_20231023」有对应原表时按日期备份删除；英文表名的月日需带分隔符，如「Report_0513」
  • 多个日期版本：同一名称有多个日期版本、但没有不带日期的原表时（如 20170113要介護度別状況調査表、20161207要介護度別状況調査表），只保留日期最新的一个，其余默认标为「删除」
  • 旧版工作表：名称以「旧」开头的表默认标为「删除」，不要求存在同名原表或对应的「新」表。例如只有 レイアウト(1ページ)、レイアウト(複数ページ) 和 旧レイアウト 时，旧レイアウト 也默认删除；「新旧対照表」「復旧手順」不受这条规则影响，可手动切换为保留
  • 新旧版本改名：同一工作簿里同时有「新X」和「旧X」时（括号前有无空格、全角半角都算，如 新レイアウト(介護給付費請求書1) 与 旧レイアウト (介護給付費請求書1)），执行后「新X」去掉开头的「新」字改为「X」（标签上「新」字带删除线），Excel 会自动更新公式与打印区域里的表名。旧表没有全部删除、新表被标为删除或待定、去掉后与现有表重名时不改名
  • 没有「旧」表的「新X」：旧版早已不在，「新」字没有意义，执行后同样去掉开头的「新」字（如 新レイアウト（２ページ以降） → レイアウト（２ページ以降）），按去掉后的名字判断是否待定。「新規」「新旧」「新着」这类「新」是词的一部分的表名不改；新表被标为删除或待定、去掉后与现有表重名时也不改名
  • 自动生成：名称以「自動生成」开头的工作表（如 自動生成_引数、自動生成_JSON）无需原表，默认标为「删除」
  • 明确写着备份：名称含 bk / ｂｋ / BK / bak / backup / バックアップ / 备份（后面可接编号，如 写真管理ｂｋ２）的工作表不需要原表，默认标为「删除」；Bkup、SBK 这类单词内部的不算
  • 没有内容的表：整张表空白，或只有一格写着「無」「なし」「該当なし」「－」「ー」「N/A」这类占位字，且没有图片、图形、批注的工作表，不看名字默认标为「删除」（如只有 A1=無 的 JSONサンプル）。鼠标停在标签上会提示
  • 灰色或黑色标签：Excel 里工作表标签是灰色或纯黑色的，不看名字默认标为「删除」（纯白、蓝灰不算）；灰色标签导出 PDF 时也跳过。鼠标停在标签上会提示
  • 编号后缀：名称末尾为「(2)」「（３）」等括号数字的工作表默认保留，即使标签是灰色或黑色；需要时可手动改为删除。编号后另有日期的不属于此规则
  • 「レイアウト_オプション」不会仅因名称包含「レイアウト」而标为待定，默认保留。
  • 名称包含：名称完整包含同工作簿另一个表的名称、但多出的部分不是上面的标记时（如「一覧」与「一覧詳細」），可能是备份也可能是正式明细表，默认标为「待定」，不默认删除（Sheet1 与 Sheet12 这种数字连在一起的不算；多出的部分整段在括号里的也不算，如「レイアウト」与「レイアウト(介護給付費請求書1)」；自己有备份表的原表也不算，如有「精神科基本療養費20260402」时的「精神科基本療養費」；多出的只是一个英文词的也不算，如「サンプル」与「JSONサンプル」、「一覧」与「CSV一覧」，new / tmp / test / work 这类临时版本词除外）
  • 单击切换：直接单击任意工作表标签，即可在「保留 → 删除 → 待定 → 保留」之间循环切换，仅靠颜色区分状态（每个工作簿至少保留 1 个工作表）
  • 预览确认：点卡片上的「🖼 预览」会在新标签页显示该文件每个工作表的预览图（打印出来的第 1 页），单击预览图同样能切换状态并与本页同步，还会提示内容完全相同或高度相似的表。标好后点底部「✓ 标记完成，返回精简 Sheet」（或左上方「← 返回精简 Sheet」）回到本页，刚才那张卡片的边框会发亮，最后在本页统一「确认执行」
  • 改表名：在「🖼 预览」里单击卡片下方的表名就能改名（最多 31 个字，不能含 : \ / ? * [ ]，不能和本文件剩下的表重名），回车确认、Esc 取消，清空或改回原名就是撤销；本页标签会显示「✏️ 新名字」，点「恢复默认」或重新扫描也会撤销。确认执行时和删表一起改，手动改过名的表不再自动去掉「新」字，标为删除的表不改名；Excel 会自动更新公式与打印区域里的表名
  • 存疑待定：标为「待定」的工作表本次保留不删，文件名和表名都不改，可以点「🖼 预览」看预览图后再决定

删表前，其他工作表中依赖待删表的公式会自动转成当前计算值，保留格式。无法保留引用值或发现新增引用错误时，该文件不保存。
