精简 Sheet

扫描全部工作表（含子文件夹），单击标签即可在「保留 / 删除 / 待定」三种状态间切换

使用说明
  • 自动递归扫描所选文件夹及其所有子文件夹下的 Excel 文件
  • 自动初筛：名称含日期（20220929，或 2018-02-26、(2018.02.26) 这类带分隔符、带括号的写法，以及末尾不带年份的月日如 0513）、bak / backup、old / 旧（「新旧」「復旧」除外）、バックアップ / 备份、コピー / copy / 副本，或复制产生的「(2)」「（３）」后缀（后面可再接日期，如「(2)_20221005」），且同工作簿存在原表的，默认标为「删除」，并用马克笔下划线标出原表与备份表的同名部分
  • 多个日期版本：同一名称有多个日期版本、但没有不带日期的原表时（如 20170113要介護度別状況調査表、20161207要介護度別状況調査表），只保留日期最新的一个，其余默认标为「删除」
  • 新旧版本：同一工作簿里同时有「新X」和「旧X」时（括号前有无空格、全角半角都算，如 新レイアウト(介護給付費請求書1) 与 旧レイアウト (介護給付費請求書1)），「旧X」默认标为「删除」；执行后「新X」去掉开头的「新」字改为「X」（标签上「新」字带删除线），Excel 会自动更新公式与打印区域里的表名。旧表没有全部删除、新表被标为删除或待定、去掉后与现有表重名时不改名
  • 自动生成：名称以「自動生成」开头的工作表（如 自動生成_引数、自動生成_JSON）无需原表，默认标为「删除」
  • 名称包含：名称完整包含同工作簿另一个表的名称、但多出的部分不是上面的标记时（如「一覧」与「一覧詳細」），可能是备份也可能是正式明细表，默认标为「待定」，不默认删除（Sheet1 与 Sheet12 这种数字连在一起的不算；多出的部分整段在括号里的也不算，如「レイアウト」与「レイアウト(介護給付費請求書1)」；自己有备份表的原表也不算，如有「精神科基本療養費20260402」时的「精神科基本療養費」）
  • 单击切换：直接单击任意工作表标签，即可在「保留 → 删除 → 待定 → 保留」之间循环切换，仅靠颜色区分状态（每个工作簿至少保留 1 个工作表）
  • 预览确认：点卡片上的「🖼 预览」会在新标签页显示该文件每个工作表的预览图（打印出来的第 1 页），单击预览图同样能切换状态并与本页同步，还会提示内容完全相同或高度相似的表。标好后点底部「✓ 标记完成，返回精简 Sheet」（或左上方「← 返回精简 Sheet」）回到本页，刚才那张卡片的边框会发亮，最后在本页统一「确认执行」
  • 存疑待定：标为「待定」的工作表本次保留不删，文件名和表名都不改，可以点「🖼 预览」看预览图后再决定
