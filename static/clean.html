精简 Sheet

扫描全部工作表（含子文件夹），单击标签即可在「保留 / 删除 / 待定」三种状态间切换

使用说明
  • 自动递归扫描所选文件夹及其所有子文件夹下的 Excel 文件
  • 自动初筛：名称含 YYYYMMDD 日期、bak / backup、old / 旧（「新旧」「復旧」除外）、バックアップ / 备份、コピー / copy / 副本，或复制产生的「(2)」「（３）」后缀（后面可再接日期，如「(2)_20221005」），且同工作簿存在原表的，默认标为「删除」，并用马克笔下划线标出原表与备份表的同名部分
  • 自动生成：名称以「自動生成」开头的工作表（如 自動生成_引数、自動生成_JSON）无需原表，默认标为「删除」
  • 单击切换：直接单击任意工作表标签，即可在「保留 → 删除 → 待定 → 保留」之间循环切换，仅靠颜色区分状态（每个工作簿至少保留 1 个工作表）
  • 存疑待定：标为「待定」的工作表本次保留不删，并在执行后为该 Excel 文件名与该 Sheet 名前加上「❓」图标，按名称排序即可集中人工确认
