问题格在 Excel 里按问题标色：
📖 程序会怎么做 每张表导出 PDF，对照 Excel 里的文字找出被切掉、被挡住的字，在 Excel 里按问题标色

🔍 扫描查哪些表、怎么查

  • 查可见的表；変更履歴、备份表、灰色标签的表不导出也不查，表名里有「レイアウト」「雛形」「雛型」的免检。
  • 每张表导出一次 PDF，把 PDF 上印出来的字和 Excel 格子里的字对照，找出被切掉、被边框压住、超出格子被裁的地方。
  • Excel 没改过、「调整页面」已经导过这张表的 PDF 时，直接用那份，不再导。
  • 导出一律按宽一页、高自动（和所有导出 PDF 一样）；横竖、向下取整照 Excel 现在的设置，那两样在「调整页面」定。
  • 单个文件卡住超过上面选的时间，就结束后台 Excel、跳过这份，留给人工检查。

🎨 怎么标色

  • 待人工处理的格子按问题类型标底色（条件格式，带 CHE_MARK 标识，单元格原来的颜色不动）；一格有几种问题时黑底黄字；有问题的表，标签标成橙黄色。
  • 点上面的色块可以换底色，颜色记在这台电脑的浏览器里，下一次扫描或复检生效。
  • PDF 上看得出的毛病都算必须改、都标色：字被截断只印出前半段、压线（半截字）、超出格子被裁、###、被分页切开。PDF 里没对上文字的列成「扫一眼」。
  • 人工改好并复检通过，或提交为蓝 / 绿后，程序清掉对应的标色。上传前也会自动清掉全部标记。

🚫 扫描不动的

  • 不自动加高、不开换行、不改列宽、原有样式和分页线。
  • 会把视图存成分页预览、存下标记颜色；原来的选区和显示缩放保留。
  • 关闭网页后任务继续，电脑和服务要保持运行。

🔁 扫完以后

  • 在下面的单元格工具箱按分类选工具，点「🛠 只修这一类」或最下面「🛠 统一修改」：程序改、保存、再复检。工具解决不了的点「📂 打开下一批」（一次最多 10 份）自己在 Excel 里改。
  • 复检整份重查：先去掉这份所有表的标记再全部重新检测，原来的黄色项全部翻篇，这次查出的重新标色；上次检测后没改过的文件不重新导出。
  • 勾了「改完关掉文件后自动复检」时，打开过的文件在 Excel 里改完、保存、关掉，就自动复检这一份（Excel 还开着的不动）。

    文件默认折叠，点击「展开卡片」或标题栏空白处后加载内部卡片，再点可收起。标题栏复选框用于「打开选中文件」，不会改变小卡片颜色。鼠标停在展开的小卡片上，按左 Alt 查看大图；再次按左 Alt 或 Esc 关闭，回到原来的浏览位置。大图内的小截图可悬停放大 1.5 倍。

    卡片按文件放在各自的框里，文件按处理顺序排；筛选颜色时没有这种颜色卡片的文件框暂时不显示。单击卡片：蓝 → 绿 → 黄 → 蓝，三种颜色均可自由切换，卡片位置不变。蓝色表示你认可结果，提交后移出列表，不额外修改 Excel。筛选后改了颜色的卡片暂时留在原位，重新点筛选按钮才按新颜色过滤。点卡片左上角圆圈可多选，文件框上的「选中本文件的卡」一次选中这个文件的卡，用底部悬浮条全选、反选或批量改色。复检和提交在后台忙时也能点，排在当前任务后面接着做；按钮不可点时鼠标移上去看原因。绿色忽略这个问题（以后扫描不再报）；黄色留给人工处理。扫描和复检不自动修改行高、换行或原有样式。颜色先保存为标记，提交后统一执行。
