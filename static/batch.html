历史自定义配色：自动保存在本机浏览器，可点选复用；独立的「修复颜色」页面会一并检查。

「只扫描」不改行高；首次会比较各 Sheet 的横向、竖向，已有有效方向记录时直接复用，比全自动修复快；检出的问题全部变成黄色人工项，并在原 Excel 里给这些单元格加一条条件格式，显示上面的底色和字色（单元格本身的格式不动，不影响排版）。勾选「全自动处理也标色」时，全自动处理提交后转人工的黄色项也用这个颜色标（处理过程中不改颜色）。人工改好、复检通过，或提交为蓝 / 绿后，自动删掉这条规则；表里原有的条件格式不动。

两种方式都先把全部文件扫描完。全自动处理扫完后开始逐行修，这时可以点「转人工」：做完当前这一行就停，还没轮到的问题转为黄色人工项（已修好的保留）。人工处理累了可以点「转回自动」：转人工后改过的文件整份重新检测，你改过行高的行和自动试过没通过的留给人工，其余交回自动接着修。两边可以反复切换。

扫描完成后，所有可见工作表会保存为「分页预览」，没有检出问题的文件也会处理。无需预先逐项确认；扫描与自动修复会直接保存原 Excel，请先保留原件。关闭网页后任务继续，电脑和服务需保持运行。

结果审核按文件分组，每个单元格一张卡片

文件默认折叠，点击「展开卡片」或标题栏空白处后加载内部卡片，再点可收起。标题栏复选框用于「打开选中文件」，不会改变小卡片颜色。鼠标停在展开的小卡片上，按左 Alt 查看大图；再次按左 Alt 或 Esc 关闭，回到原来的浏览位置。大图内的小截图可悬停放大 1.5 倍。

卡片按文件放在各自的框里，文件按处理顺序排；筛选颜色时没有这种颜色卡片的文件框暂时不显示。单击卡片：蓝 → 绿 → 黄 → 蓝，三种颜色均可自由切换，卡片位置不变。蓝色表示你认可结果：有可采用的「最后一次尝试」时，提交按那次的行高写入原文件；没有试修方案时按人工确认放行，不额外修改 Excel。筛选后改了颜色的卡片暂时留在原位，重新点筛选按钮才按新颜色过滤。点卡片左上角圆圈可多选，文件框上的「选中本文件的卡」一次选中这个文件的卡，用底部悬浮条全选、反选、批量改色或「🤖 自动调整选中」。觉得问题简单的黄卡可以交给程序自动加高：卡片上的「🤖 自动调整」只调这一格，文件框上的「🤖 自动调整这个文件」调这个文件的全部黄卡；自动试过没修好的格子，文件改过后才会再试。「只扫描」进行中，已扫完的文件也能点，先排队，全部文件扫完后接着自动调整；复检和提交在后台忙时也能点，排在当前任务后面接着做；按钮不可点时鼠标移上去看原因。绿色还原并忽略，黄色还原后人工处理。颜色先保存为标记，提交后统一执行。
