加图标

📖 程序会怎么做 PNG 生成多尺寸 .ico（.ico 直接用）存进图标库；可设给已有文件夹；能导出 / 导入换电脑

🖼️ 生成图标

  • 拖进来的图片（最好是透明底 PNG）缩成 16 / 20 / 24 / 32 / 40 / 48 / 64 / 96 / 128 / 256 共 10 个尺寸，合成一个 .ico。
  • 勾选「自动裁掉透明边」会去掉原图周围的透明留白，并忽略接近全透明的杂点。成品 .ico 是正方形，长方形图案会按比例居中，上下或左右会留白。
  • 库里已有的图标可以点「重新裁剪」，用保存的原图重新生成。
  • 原图原样留一份。图片小于 128 像素时大图标会糊，会提醒你。
  • 导入时先比对原文件指纹，文件内容相同就直接跳过。文件内容不同时，再比较裁掉透明边后的尺寸和像素。

📁 文件夹图标在哪里设

  • 这一页管图标本身（上传、分类、改名、替换、删除、导出导入），也能给已经存在的文件夹设 / 还原图标。
  • 网站自带的图标放在固定分类「系统图标」里，随程序更新，只能用（套文件夹、换工具箱图标、下载 .ico），不能改名、替换或删除。自己上传的图标分类名随便起，只是不能叫「系统图标」。
  • 拖 .ico 进来不会重新生成，原文件直接用（里面各种尺寸都留着），只拿最大的一张做预览和查重复；「自动裁掉透明边」和「重新裁剪」对 .ico 不起作用。
  • 已经存在的文件夹：在右边「设为文件夹图标」填路径就能设 / 还原。新建文件夹时也可以顺便选：目录结构模板里每个目录可以挑图标，船票页建 Ticket 文件夹时也能选。
  • 套上去的是复制件：以后删掉图标库里的图标，文件夹的图标也不会坏。替换图标图片时，套过它的文件夹一起换成新图。
  • 资源管理器有图标缓存，看不到变化时按 F5 或过一会再看。

💾 存在哪里

  • 图标库在 桌面\handle-excel\程序数据\图标库，换新版本（重新下载 ZIP）不会丢。
  • 换电脑：点「⬇ 导出」存一个 zip（点了分类就只导这个分类，批量管理里勾了就只导勾的；系统图标不导），到新电脑点「⬆ 导入图标 zip」或直接把 zip 拖进来。导入是合并：名字分类都留着，和库里重复的自动跳过；「用在哪些文件夹」「工具箱图标」是旧电脑的设置，不带过去。
  • 「工具箱图标」可以把主页工具箱里某个工具的图标换成图标库里的图，恢复默认就回到原来的图。
