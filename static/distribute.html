先生成清单，确认后再复制

JSON 里每个文件夹的 source 接在「来源根目录」后面，destination 接在「目的地根目录」后面。整个文件夹连子文件夹一起复制，只复制 Excel 表格文件（.xls / .xlsx / .xlsm / .xlsb / .xlt / .xltx / .xltm，~$ 临时文件不算），其他文件不管。只复制不移动，来源文件原样保留。目的地已有同名文件时直接覆盖，文件名不改，覆盖了哪些写在复制记录里。

生成清单只读不改。开始复制前会再查一遍来源，生成清单后来源有变化就不复制，需要重新生成。关闭网页后任务继续。
