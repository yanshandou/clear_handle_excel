选两份要对比的 Excel

📖 程序会怎么做 只读两份文件，不开 Excel、不改文件；报告是一个 .html，双击就能看，可以直接发给别人

📋 怎么选

  • 每边填完整路径（可以粘贴「复制为路径」带引号的），或点「选择文件」，或直接把文件拖到框里。
  • A 当旧版（左边、红色 −），B 当新版（右边、绿色 +），点 ⇄ 可以对调。
  • 支持 .xlsx / .xlsm / .xltx / .xltm；旧的 .xls 要先在 Excel 里另存为 .xlsx。

🔍 比哪些

  • 表：多了 / 少了哪张表、表的顺序。
  • 每个格子：文字、公式、公式结果、批注、超链接、字体、字的颜色、填充色、边框、对齐、数字格式、保护。
  • 整张表：行高列宽、隐藏行列、合并、冻结窗格、打印设置、页眉页脚、图片图形、标签颜色、显示隐藏、条件格式、数据验证、自动筛选、工作表保护。
  • 工作簿：定义的名称、工作簿保护。

📄 报告

  • 左右两栏效果图（不一样的格子盖红 / 绿色块）+ 逐条差异清单，清单一条不省略；可以按类型筛、搜索。
  • 报告另存一份在程序数据的 excel_reports 文件夹里。
